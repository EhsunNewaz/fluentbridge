## 📊 **Learning System Architecture**

### **Enhanced 6-Part Assessment System**
```
1. Phonics Diagnostic (10 min) - Foundation readiness check
2. Overall IELTS (15 min) - Comprehensive skill assessment  
3. Reading Skills (5 min) - Detailed reading analysis
4. Writing Skills (7 min) - Writing capability check
5. Listening Skills (5 min) - Audio comprehension test
6. Speaking Skills (8 min) - Text-based speaking assessment

Result: Personalized learning path with Bengali-first content recommendations
```

### **Learning Content Hierarchy**
```
3 Learning Tracks:
├── Track 0: Phonics Foundation (Prerequisites)
│   ├── Bengali to English Sound Mapping
│   ├── Basic Phonics Patterns  
│   ├── Advanced Sound Combinations
│   └── Pronunciation for IELTS Speaking
├── Track 1: IELTS Preparation (Core Offering)
│   ├── IELTS Writing Mastery
│   ├── IELTS Reading Skills
│   ├── IELTS Listening Practice
│   └── IELTS Speaking Confidence
└── Track 2: Grammar Foundations (Supporting)
    ├── Essential Grammar
    └── Advanced Grammar Structures

Structure: Track → Course → Module → Lesson → Content (Video/Text/Interactive/Quiz)
```

## 💾 **Database Schema Essentials**

### **Core Tables for Phase 1 Implementation**
```sql
-- Authentication & Users
users (id, email, full_name, bengali_name, phone, preferred_language, target_band_score)
user_roles (user_id, role) -- 'student', 'instructor', 'admin'

-- Learning Content (4-level hierarchy)
learning_tracks (id, name, slug, description, level, order_index)
courses (id, track_id, name, slug, description, level, estimated_hours, is_free)
course_modules (id, course_id, name, slug, description, order_index)
lessons (id, module_id, name, slug, content, bengali_content, lesson_type, difficulty_level)

-- Phonics System
phonics_sounds (id, english_sound, ipa_symbol, bengali_equivalent, bengali_explanation, practice_words)
user_phonics_progress (user_id, sound_id, mastery_level, practice_sessions)

-- Assessment System  
assessments (id, name, type, duration, total_points)
assessment_questions (id, assessment_id, question_text, bengali_hint, options, correct_answer)
user_assessment_results (user_id, assessment_id, total_score, skill_breakdown, recommendations)

-- Progress Tracking
course_enrollments (user_id, course_id, progress_percentage, enrolled_at)
user_lesson_progress (user_id, lesson_id, status, completion_date, score, difficulty_rating)

-- Community Features (Phase 3)
study_groups, study_group_members, speaking_partner_preferences, lesson_feedback
```
